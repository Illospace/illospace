# Roadmap

Illo Brain is in early open-source preview. The near-term roadmap is:

- reliable local setup with safe defaults;
- clearer self-hosting docs and systemd templates;
- stable Cortex thought/thread workflows;
- tighter project context and vault permissions;
- public skill-bundle authoring and import/export flows;
- stronger CI, release, and dependency-license checks;
- better browser/runtime diagnostics for self-hosters.

The project is not yet a hosted product or a stable library API. Public roadmap
items may shift as the runtime and UX settle.
