# Coordinate Routing Ladder

Use the lowest-complexity lane that can satisfy the user.

1. Direct answer: enough is known and no state needs to change.
2. Single tool: one inspection/action resolves the request.
3. Specialist skill: the task has a repeatable professional role.
4. Internal orchestration: multiple deliverables, parallel scopes, long chains, or explicit multi-agent work.
5. One question: action would be risky without a missing fact.

Memory is useful context, not proof. Verify stale repo, server, user, and schedule facts against live state before relying on them.
