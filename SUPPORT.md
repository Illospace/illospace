# Support

Illo Brain is an early open-source preview. The best public support path is a
GitHub issue with a focused reproduction and redacted logs.

Use private security reporting for vulnerabilities, leaked secrets, or private
data exposure. See [SECURITY.md](SECURITY.md).

Before opening an issue:

- search existing issues;
- confirm the problem on the latest public commit;
- remove provider keys, tokens, private memory content, transcripts, uploads,
  database dumps, and local hostnames from logs.
