# Governance

Illo Brain is currently maintained by the project maintainers using normal
GitHub issues and pull requests.

## Contributions

By opening a pull request, you agree that your contribution is submitted under
the Apache License, Version 2.0, unless you explicitly state otherwise in the
contribution.

Maintainers may ask for scope reduction, tests, documentation, or security
review before merging. Small, well-tested changes are easier to review than large
rewrites.

## Decision Making

Maintainers make final decisions on project direction, roadmap priority,
security posture, and release timing. Significant architecture decisions should
be documented in `docs/` when they affect public extension points or self-hosted
operators.
